# Redro Portfolio

A responsive Arabic/English personal portfolio for Redro with a charcoal-and-red visual identity.

## Features
- Projects gallery with logos, descriptions, live links, GitHub links, and optional project screenshots.
- Editable biography, skills, contact details, projects, and stories.
- Arabic and English interface.
- Static HTML/CSS/JavaScript; no build step required.

## Important limitation
Edits made through the site are stored in the current browser's localStorage only. They do not update the GitHub repository or appear for other visitors. Shared editing requires a backend or content-management workflow.
